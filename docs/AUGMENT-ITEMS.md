# 海克斯装备建议（1.1.5）

数据文件 `hero_augment_items.json` 是可选文件，须写入公开数据清单 `files`，带 SHA-256 和大小。文件没有、当前英雄没有配置或配置无效时，不显示空面板，也不拿普通出装榜代替。

目前在命运之武器（3081）的三选一卡片上启用。1.1.5 起装备建议是半透明面板，默认放在卡片下半部分的空白处，不盖住说明文字；海克斯标签放在下方时移到卡片标题上方。只在这张卡出现时显示，不判断玩家是否出装，不记住玩家是否选择了它。建议使用全体数据，避免分段后样本更少。

结构是「英雄 ID → 海克斯 ID → 配置」：

```json
{
  "17": {
    "3081": {
      "source": "community",
      "show_winrate": false,
      "items": [
        {"item": "4645"},
        {"item": "3135"}
      ]
    }
  }
}
```

这只是格式示例，不代表提莫的实际推荐。不要直接作为正式数据发布。

- `source` 必填：`stats`（统计参考）、`community`（社区推荐）、`manual`（人工推荐）。人工维护此文件即可随数据更新下发，不需改程序。
- `items` 按给定顺序展示，最多三件；重复装备跳过。客户端不按不稳定的小样本胜率自行排序。
- `item` 是装备 ID（含模式专属 ID）。名字和图标从现有腾讯装备资料中取；不认识的装备可以另写 `name`，此时可能暂时只有文字。
- 每件可以带整数 `games`、`wins`，客户端计算胜率。统计必须是当前英雄持有命运之武器时的装备样本，不能混入普通出装统计；结算装备不能证明购买顺序，统计发布时须说明口径。
- 配置可以带 `total`（这个英雄持有该海克斯的有效样本数），客户端保留 `games / total`。本轮 1.1.5 修订默认不显示选取率；需要显示时，数据源显式写 `show_pick_rate: true`，且分子分母必须同口径。
- 单件可以带 `low_sample: true`，显示“样本偏少”；推荐门槛由出数据时决定，不写在客户端。小样本应在发布数据源前筛除，不依靠提示代替筛选。
- 一件都不够格时：`items` 留空并写 `note`（如“样本太少，暂无装备参考”），1.1.5 只在底部显示这一行，说明照常显示；1.1.4 不显示。
- 胜率非必填。配置的 `show_winrate: false` 隐藏全部胜率；单件也可以写 `show_winrate: false`。没有胜负数据时只显示装备，不虚构数字。
- 图标加载复用现有装备缓存，后台下载；新增面板区域也登记到截图遮挡列表，防止识别自己的文字。

## 命运胜率、百分点与显示字段（本轮 1.1.5 修订）

当前数据只展示装备图标、名称及相对英雄基准的加减（用户 2026-11-06 决定）。胜率和样本数保留在数据中，但不显示；没有新增云控。数据源可以为每个英雄的 3081 配置以下字段：

```json
{
  "17": {
    "3081": {
      "source": "stats",
      "show_winrate": true,
      "show_rate": false,
      "show_sample_size": false,
      "show_pick_rate": false,
      "show_delta": true,
      "baseline": {"games": 10000, "wins": 5200},
      "items": [{"item": "4645", "games": 2000, "wins": 1140}]
    }
  }
}
```

这是计数示例，不代表真实推荐。对应显示：`影焰　+5.0`。写 `show_rate: true`（默认）时显示 `影焰　胜率 57.0% · +5.0`，没有 `baseline` 时只显示胜率。

- `show_sample_size` 默认 `false`，设为 `true` 额外显示如 `2,000局`；计数不会因隐藏而从数据中丢失。
- `show_pick_rate` 默认 `false`，设为 `true` 且 `total` 有效时才显示比例。仅想显示胜率和样本数时无需开启它。
- `baseline` 可选，当前交该英雄基础统计的 `games` 和 `wins`，和三选一卡片上海克斯加减用的基准相同。人群必须包含该装备统计行，不能只合计筛选后的前三条候选。
- `baseline` 和装备行的计数必须是整数，`games > 0`、`0 <= wins <= games`。装备样本数、胜场和负场均不能多于基准中对应的计数。
- 差值直接计算为 `(装备 wins/games - 基准 wins/games) × 100`，单位为百分点，界面保留一位小数并带正负号，不写单位；**不做样本平滑，不使用现有海克斯 `smoothing_games` 参数**。
- `show_delta` 默认 `true`。设为 `false` 可只显示原始胜率；缺少或不合法的基准也只显示原始胜率，不猜测或回填基准。`show_winrate: false` 或用户关闭全局胜率显示时，胜率和差值一起隐藏。
- 客户端保留数据源的装备顺序，既不根据原始胜率，也不根据差值重排。筛样本、推荐候选和顺序由服务端完成。
- 本修订不改变现有海克斯评分平滑；不改变三件套的 `ordered` 协议。只修改数据文件不足以让旧客户端显示新增差值或采用新的默认隐藏策略，需使用包含本修订的客户端。
