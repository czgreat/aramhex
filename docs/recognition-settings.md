# 识别参数云控

以下 Settings 字段可通过现有云控 settings 规则的 defaults / force 下发；离线仍使用本机缓存。

| 字段 | 默认值（保持原行为） | 云控范围 | 含义 |
| --- | --- | --- | --- |
| recheck_seconds | 5.0 | 1–60 秒 | 画面不变、已发布卡片的逐列复查周期 |
| pending_seconds | 0.9 | 0.1–5 秒 | 待确认读数持续超时后暂时隐藏该列 |
| low_match_reads | 3 | 1–10，严格整数 | 连续低命中的新 OCR 批次数达到阈值后，清掉内部稳定卡组 |
| active_hold_s | 5.0 | 0–30 秒 | 三选一关掉后保持快扫的时长，0 表示不额外保持 |

复查周期不允许 0，避免每轮强制重读或完全关闭复查；其余范围限制等待时间和连续确认次数。
布尔、字符串、非有限数、越界值忽略并按现有云控规则记日志；low_match_reads 不截断小数。
识别线程在每轮扫描前复制最新参数，不清除跟踪，不重建识别器。active_hold_s 在调度时直接读设置。
force 撤掉恢复原值，保存本机设置时不保存被 force 覆盖的值；defaults 遵守玩家自行修改的项。

默认值边界测试覆盖 5 秒复查、0.9 秒待确认超时、3 批真实 OCR 后清内部状态，以及 5 秒快扫保持。
沿用现有引擎连续三次读空后关闭标签的条件；low_match_reads 调的是识别器内部状态，不改变该条件。
颜色策略由独立 PR 的 color_check 控制，本改动不增加“名字完全对上时信文字”的开关。
