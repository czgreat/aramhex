# 1.1.2 整块 OCR 标题优先验证

整块扫描会先检测文字，再给检测框逐行认字。卡片正文和其他文字也进入识别模型。
本次保留检测区域、分辨率、模型、单线程限制和扫描频率，只减少能安全跳过的正文认字。

候选位置只决定读取顺序。候选最大检测序号之前的全部框，以及这些框的同一行邻居，必须先读取。
使用原 `_pick_row` 验证完整前缀已经存在三个独立强匹配；任何后续行的几何上界可能达到四列时完整回退。
整数坐标映射、严格行距/横距阈值与原算法一致。置信度不足、遮挡、缺卡、错误校准等不确定情况继续读取剩余框，
不重复检测或识别已读框。韩文等独立模型暂时保持原完整路径。

## 235 回放结果（2026-10-24）

Windows 11，虚拟机 16 vCPU / 16 GB，Ryzen 9 5950X，RX 580；RapidOCR 3.9.2、ONNX Runtime 1.30.0。
推理仍限制 1/1 线程，OpenCV 单线程，后台测试进程使用 BelowNormal 优先级。测试时游戏和 OBS 保持运行，OBS 未录制。

54 组成对调用（共 108 次）中，识别 ID 和发布框坐标均无差异。包含 24 张原始截图（22 张三选一、2 张选英雄）、
重复回放、1080p/1440p 缩放、错误校准、画面平移、遮挡、变暗、助手浮层、空白画面和语言合成用例。

遮掉一张时保留其余两列，遮掉两张时不返回三选一；错校准和画面平移均完整回退，结果与原路径相同。
另加四组带九行正文的语言合成对照，共计 58 对、116 次调用，仍未发现 ID 或框坐标差异。
感叹号区分 ID、英文长名及中文组从 12 框读取 3 框；繁中组完整回退。

Windows 235 全量回归 510 项通过（69.46 秒）；Linux 197 为 495 项通过、4 项跳过（24.64 秒）。
固定测试包含失准正文锚点仍取真标题、prefix 邻域、四列上界、多个候选累计、低置信度回退、
整数缩放临界值和自定义模型保持原路径。子代理独立复核并作两轮共 50,000 组几何随机对照，未发现选行差异。

## 限制与验收

原始保存图含助手浮层，主回放使用人工近似遮罩，并非当时真实 `drawn_rects`。54 组结果是新旧对照，
并非 54 个独立人工标注正例。只有三个已人工核实标题的原始画面用于明确 ID 验收。
22 张真实三选一截图中四张新旧路径均未返回三选一；不能据此宣称识别准确率 100%。
完整回退的真实帧最大增加约 231 ms（16.5%），平移用例增加约 167 ms；需继续观察实际玩家日志。
合成画面不代表真实棱彩卡或所有语言覆盖；拆分 batch 会改变 padding，不能声称 OCR 逐字数学等价。

这次未完整复现用户历史 20 多秒个案，未测量真实游戏 FPS，不能以 OBS 的渲染 FPS 代替游戏帧率。
普通日志增加“检测框 / 实际认字 / 提前完成”计数，用于后续判断收益和回退频率，不增加普通日志中的识别正文。
之前的切屏过时帧保护、逐列稳定处理和官方资料离线化继续保留，本次不改变生产云控或服务器。
