# 海克斯名字与稀有度热修

云控 config.json 可选字段（仅格式示例，本 PR 不更改线上配置）：

```json
{
  "augments": {
    "aliases": {"1005": ["喂鸣喂鸣"]},
    "rarity_fix": {"2078": "gold"}
  }
}
```

两个字典各最多读取前 128 项。ID 必须是无前导零的 1–9 位正整数字符串。
每个 ID 最多 8 个别名，每个去掉两端空格后长 1–64 字符，不允许控制/格式字符；
全配置最多 512 个别名。重复名字去重。超过上限的剩余项忽略并记 INFO。
格式错误的条目忽略并记 INFO，合法的同级条目继续使用。稀有度仅支持 silver、gold、prismatic。

按 ID 合并安装包里的 augment_aliases.json / tencent.RARITY_FIX；同 ID 的云控值优先。
云控 aliases 为列表替换该 ID 的安装包别名（空列表可撤掉内置误别名），主名字及语言名字保留。
例如云控给 1005 只下发 ["新写法"]，该 ID 内置的「喂鸣喂鸣」就不再作为别名；
若两种写法都要保留，应下发 ["喂鸣喂鸣", "新写法"]。
别名只加给当前名字表存在的 ID，不凭云控创建海克斯。云控没有的 ID 保留安装包规则。

稀有度以运行时副本覆盖静态资料和单英雄行，同时用于颜色核对和评分展示；
不修改已校验的官方资料包、清单、内置文件或磁盘缓存。撤掉云控后恢复安装包规则和原始资料。
原始腾讯解析仍只用安装包更正表，避免临时云控写进持久资料后无法撤回。

新配置继续使用已有 cloud.json 缓存，离线启动时经过同一校验。识别线程下一轮循环
只有名字表、稀有度或匹配设置变化才同步，清列缓存强制重读，但保留已发布卡组和连续确认状态；
后台不在 OCR 中途换表，普通数据检查不打断选卡。
未改服务器、线上配置、匿名统计，也未新增网络请求。
