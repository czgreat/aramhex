# 下一版（随海斗 4.0 一起做）

海斗 4.0（16.21）外服 10-21、国服约 10-22 上线。下面这些攒到那时一起做，一起发一个版本（加功能，版本号 1.1.0）。先去测试服确认 4.0 的具体内容再动手。

## 1. 尊我为王显示「无数据」

尊我为王完成任务后会变成一个随机棱彩海克斯，结算数据里只剩没完成任务的人，胜率明显偏低（局末持有者约 32%），真实胜率算不出来，统计数据里已经剔除。

- 三选一角标：一行灰字「无数据」，不打分，不参与「首选」比较。
- 主窗口三选一卡片：「无数据」，下面一行小字「完成任务后会被替换，统计不准」。
- 英雄海克斯列表：最后一行灰色，和官网数据页一样。
- 现在没有统计数据时会退回「按官方层级」估分（它的官方层级是 C，显示「可考虑刷新」），对不统计的海克斯要跳过这一步。
- 不统计名单从数据的 `meta.json` → `excluded_augments` 读，以后再有同类海克斯只更新数据，不用发版。

## 2. 数据更新提示，游戏中不打扰

| 情况 | 做法 |
|---|---|
| 开了自动更新，不在游戏里（大厅、排队、结算） | 后台下载并换上，右下角提示一下「数据已更新（截至 X，Y 万局）」 |
| 开了自动更新，正在游戏里 | 可以先下载，但不换数据、不提示；回到大厅再换、再提示（一局里推荐前后一致） |
| 没开自动更新 | 只在游戏外问「检测到新数据，是否更新？」 |

下载失败时提示继续用现有数据。云控公告弹窗同样改成游戏中不弹（现在定时查云控时可能在游戏里弹出来抢焦点）。

## 3. 掷骰狂人看对面阵容

掷骰狂人在对面有召唤物英雄时更强。16.20 全部对局（3.74 亿条参与记录）里，拿了掷骰狂人的人比同组所有人高出：

| 对面会掉骰子的英雄 | 0 个 | 1 个 | 2 个 | 3 个及以上 |
|---|---|---|---|---|
| 高出（百分点） | +2.2 | +3.2 | +4.1 | +5.7 |

单个英雄：玛尔扎哈 +5.3、婕拉 +4.8、黑默丁格 +4.0、纳亚菲利 +3.8、伊莉丝 +3.7、约里克 +3.5、茂凯 +3.3、萨科 +3.1、乐芙兰 +3.0、费德提克 +2.7、孙悟空 +2.6、妮蔻 +2.1、安妮 +2.1、艾翁 +1.5。

- 三选一出现掷骰狂人时，角标下一行小字：「对面蚂蚱 +5.3、婕拉 +4.8」；对面没有就不加。
- 数值由数据端按「海克斯 × 对面英雄」算成一张小表随数据下发，不写死；上线前改成和同英雄自己比（现在是和同组所有人比）。
- 对面阵容从游戏内 2999 接口（Riot 官方只读）的 playerlist 拿。**10-18 国服海斗实测可用**：10 人的英雄、阵营（拿自己的名字对出敌我）、等级、装备、符文、召唤师技能、战绩都有；别人的海克斯没有。gamestats 的 mapTerrain 在灵魂莲华图上也是 Default，认不出地图。
- 以后别的海克斯、出装也可以按对面阵容推荐，先不做。

## 4. 海斗 4.0 适配

- 8 个嘉宾（乐队）：K/DA、真实伤害、心之钢、五杀乐队、咖啡甜心、命令行、迪斯科（太空律动）、小蜜蜂乐队。每局一个，出兵前后揭晓。
- **不按嘉宾分开统计，也不在游戏里认嘉宾（10-18 定）。** 对局数据里没有嘉宾：客户端接口、2999、游戏日志、结算战绩（网关原始数据两局 430 多个字段逐个比过，只有时长、投降相关的不同）、时间线都查过。游戏里能从左上角的嘉宾卡片认出来，但统计那头接不上，认出来也给不了按嘉宾的胜率。胜率按所有嘉宾混在一起算。
- 例外：嘉宾专属海克斯（五杀乐队 3170–3173、3176）只在对应嘉宾的局里出现，胜率本身就是那支乐队局里的。
- 心之钢贴纸不进结算数据（贴了贴纸海克斯编号也不变），算不出贴纸对胜率的影响。
- 新海克斯的名字已经能识别；统计里还没有的新海克斯显示「无数据」，不再按「这个英雄几乎不选」提示刷新。

## 5. 局内认地图

- 游戏自己的日志（`Game/Logs/GameLogs/<开局时间>/*_r3dlog.txt`）开局写一行 `mapskin = Default`，读这一行就知道地图，不用认小地图。
- 客户端接口的对局信息里地图写的是「随机地图」，没有变体；2999 的 mapTerrain 也是 Default。
- 三张图对英雄胜率影响很小（16.20 约 92 万局，多数英雄只差 0.8 个百分点左右），暂不按地图拆数据。

## 6. 匿名使用统计（看留存）

现在官网统计按 IP 去重，家里宽带 IP 一两天就变，看不出「同一台电脑是不是一直在用」。

- 第一次打开时随机生成一串编号（例如 16 位十六进制）存在本地设置里；和硬件、账号、游戏名都无关，重装就是新编号。
- 只在查云控（config.json）时放在请求头里带上，不发别的东西。
- 界面上不显示，默认开；要关就把 `config.json` 里的 `send_usage` 改成 `false`。
- 服务器端统计脚本按编号算：每天新装、每天在用、次日 / 7 日留存、每台用了几天、升级新版本有多快。
- 从发这个版本开始的数据才准，之前的只有按 IP 的估算。

## 7. 退出兜底

托盘右键「退出」和游戏浮窗里的「退出」统一走一个函数：记一行日志、停后台线程、结束界面；3 秒内进程还没退干净就强制结束。测试版上出现过一次点了退出、进程一直留着、程序文件夹删不掉，原因没查清，正式版的退出代码一样，先加兜底。

## 8. 上线数据（过渡数据）

- 国服上线当天：老海克斯用 16.20 正式服的「英雄 × 海克斯」数据，新海克斯用测试服 16.21.828 的对局（10-18 已采到 1.28 万局有效局，上线前再补一次）。
- 推荐里用测试服数据的新海克斯：先按它在测试服所有英雄上的合计胜率打底，再用本英雄在测试服的局数微调；不参与「样本太少」判断；标「测试服数据，样本少」。
- 第二天起用正式服第一天的数据，头几天每天更新一次。
