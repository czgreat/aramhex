# 下一版（随海斗 4.0 一起做）

海斗 4.0（16.21）外服 10-21、国服约 10-22 上线。下面这些攒到那时一起做，一起发一个版本（加功能，版本号 1.1.0）。先去测试服确认 4.0 的具体内容再动手。

## 1. 尊我为王显示「无数据」

尊我为王完成任务后会变成一个随机棱彩海克斯，结算数据里只剩没完成任务的人，胜率明显偏低（局末持有者约 32%），真实胜率算不出来，统计数据里已经剔除。

- 三选一角标：一行灰字「无数据」，不打分，不参与「首选」比较。
- 主窗口三选一卡片：「无数据」，下面一行小字「完成任务后会被替换，统计不准」。
- 英雄海克斯列表：最后一行灰色，和官网数据页一样。
- 现在没有统计数据时会退回「按官方层级」估分（它的官方层级是 C，显示「可考虑刷新」），对不统计的海克斯要跳过这一步。
- 不统计名单从数据的 `meta.json` → `excluded_augments` 读，以后再有同类海克斯只更新数据，不用发版。

## 2. 数据更新提示，游戏中不打扰

| 情况 | 做法 |
|---|---|
| 开了自动更新，不在游戏里（大厅、排队、结算） | 后台下载并换上，右下角提示一下「数据已更新（截至 X，Y 万局）」 |
| 开了自动更新，正在游戏里 | 可以先下载，但不换数据、不提示；回到大厅再换、再提示（一局里推荐前后一致） |
| 没开自动更新 | 只在游戏外问「检测到新数据，是否更新？」 |

下载失败时提示继续用现有数据。云控公告弹窗同样改成游戏中不弹（现在定时查云控时可能在游戏里弹出来抢焦点）。

## 3. 掷骰狂人看对面阵容

掷骰狂人在对面有召唤物英雄时更强。16.20 全部对局（3.74 亿条参与记录）里，拿了掷骰狂人的人比同组所有人高出：

| 对面会掉骰子的英雄 | 0 个 | 1 个 | 2 个 | 3 个及以上 |
|---|---|---|---|---|
| 高出（百分点） | +2.2 | +3.2 | +4.1 | +5.7 |

单个英雄：玛尔扎哈 +5.3、婕拉 +4.8、黑默丁格 +4.0、纳亚菲利 +3.8、伊莉丝 +3.7、约里克 +3.5、茂凯 +3.3、萨科 +3.1、乐芙兰 +3.0、费德提克 +2.7、孙悟空 +2.6、妮蔻 +2.1、安妮 +2.1、艾翁 +1.5。

- 三选一出现掷骰狂人时，角标下一行小字：「对面蚂蚱 +5.3、婕拉 +4.8」；对面没有就不加。
- 数值由数据端按「海克斯 × 对面英雄」算成一张小表随数据下发，不写死；上线前改成和同英雄自己比（现在是和同组所有人比）。
- 对面阵容从游戏内 2999 接口（Riot 官方只读）的 playerlist 拿。**10-18 国服海斗实测可用**：10 人的英雄、阵营（拿自己的名字对出敌我）、等级、装备、符文、召唤师技能、战绩都有；别人的海克斯没有。gamestats 的 mapTerrain 在灵魂莲华图上也是 Default，认不出地图。
- 以后别的海克斯、出装也可以按对面阵容推荐，先不做。

## 4. 海斗 4.0 适配

- 8 个乐队：K/DA、真实伤害、心之钢、五杀摇滚、咖啡甜心、源计划、太空律动、小蜜蜂乐队。每局一个，全场共用。
- 进游戏前不知道乐队，用所有乐队合在一起的数据；进游戏后认出乐队，海克斯推荐可以考虑按乐队来（怎么做还没定）。
- 五杀摇滚的技能强化是正式海克斯编号：3170（Q）、3171（W）、3172（E）、3173（R）、3176（通用），三选一里出现时要单独处理。
- 心之钢会在部分海克斯上贴「贴纸」，选它有额外奖励；能不能识别、要不要算进推荐，测试服看了再定。
- 结算数据里怎么认乐队还不知道（地图写在对局的 `gameModeMutators`，乐队不一定在）；2999 接口里有没有乐队也要实测（16.20 的 2999 连地图都不区分）。
- 新海克斯的名字已经能识别，部分图标是占位图，上线后核对一遍。

## 5. 局内认地图、认乐队

网上的开源项目（aram-player、mayhem-tracker 等）都只分到「普通大乱斗 / 海斗」（队列 2400、模式 KIWI），没看到能认地图皮肤的。2999 接口的 `mapTerrain` 在灵魂莲华图上也是 Default，认不出来。

定下来的方向（10-18）：

- **认小地图**：右下角小地图三张图差别很大（比尔吉沃特中间是桥、灵魂莲华粉绿色、默认图冰雪色），截一块缩略图和三张样图比颜色，开局几秒就能认出，整局都在。
- **LCU**：以后可能接 LCU（客户端接口）。客户端知道这局是哪个地图变体（LCU 的地图接口带 game mutator 参数），具体从哪个接口拿、4.0 的乐队在不在里面，接的时候实测。
- 不用加载界面（大家加载时都切出去了），也不用结算数据（局内用不上）。

乐队：小地图认不出来，靠 LCU，或者截图认开局的乐队公告、界面上的乐队图标；三选一里出现五杀摇滚专属强化（3170–3176）也能确定是五杀摇滚局。

地图对英雄胜率的影响很小（16.20 约 92 万局，三张图之间多数英雄只差 0.8 个百分点左右，少数如斯卡纳、奎因在比尔吉沃特高 2～3 个点），不急；乐队效果大得多，优先。

小地图识别的做法和验证（10-18）：

- 位置不靠猜：读游戏安装目录的设置文件（PersistedSettings.json，待核对字段：小地图缩放、是否放左边、分辨率、窗口模式），加上游戏窗口位置算出小地图范围。只读本机文件，不碰 LCU。
- 只看整体颜色分布，不认细节；大小、分辨率不同时颜色分布基本不变，框偏一点、被战争迷雾挡一部分也能认。
- 三张图分不清时当作没认出，用全部地图合在一起的数据。
- 动手前先验证：确认设置文件字段；三张图在最小/最大缩放、不同分辨率下各截几张离线测，全部认对才做，不行就只靠 LCU。
- 分工：「看对面阵容」（掷骰狂人等）用 2999 就够；LCU 补地图变体、乐队、选人阶段的信息。
