# 对局中按需显示浮窗按钮

1.1.7 起固定开启，设置页没有开关。试用版里曾是默认关闭的勾选项；1.1.7 读设置时一律打开，也不算玩家改过的项。云控 `force: {"overlay_on_demand": false}` 可应急恢复常驻按钮。

## 显示规则

- 进对局（含读条）到第一次海克斯选择结束后 0.5 秒，按钮一直显示，让玩家知道它在哪；选卡期间不自动展开详情。到时按钮连同详情直接隐藏；鼠标在浮窗上、正在输入英雄、未识别英雄的提示开着时不收详情。中途才打开助手、进对局 5 分钟仍没等到海克斯选择时，也不再固定显示。下一局重新计算。
- 之后对局中没有三选一、详情已收起时，隐藏按钮窗口及其详情窗口。采用窗口隐藏，不用透明度为零的置顶窗口保留点击区域。
- 鼠标移到原按钮位置附近，按钮重新显示，点击可以打开出装、加点等详情。位置跟随设置里的左上角或右上角；1.1.7 起按钮直径 48 逻辑像素（原 40），热区在按钮外额外留 24 个逻辑像素（原 8）。移出后按钮保留 1.5 秒，方便点击。
- 展开的详情继续沿用原有的鼠标离开 5 秒收起逻辑；正在输入英雄、未识别英雄的提示照常保留。手动收起未知英雄提示后不反复弹出。
- 选英雄时的胜率标注、详情自动展开，以及三选一推荐标签继续显示。三选一推荐存在时，按钮也会显示。
- 按需模式下游戏切到后台时，隐藏游戏按钮、详情和三选一标签；回到游戏后根据原有结果恢复，不要求重新认出卡片。
- 浮窗总开关 `overlay` 1.2.0 起只有云控能关（托盘的“显示游戏浮窗”已去掉）。关闭后，移到热区也不会唤出窗口。
- 1.1.7 测试版曾在第一次选择结束后自动展开详情 8 秒（云控 `features.first_offer_details`），已改为上面的固定显示按钮，该云控项不再使用。以第一次选择为准，是因为认不出读条什么时候结束。

热区复用现有 250ms 界面定时器查询鼠标位置，没有增加鼠标钩子、透明热区窗口或截图。Windows 下使用物理像素坐标，隐藏的按钮也跟随游戏窗口移动以接收显示器 DPI 变化。界面忙时唤出可能更慢，250ms 不是绝对响应保证。

## 出装和加点详情快捷键

1.2.0 起默认不用：设置页不显示这一项，也不注册快捷键（实测不好按），只靠鼠标移到浮窗位置唤出，设置页「浮窗位置」下面写明。云控 `features.overlay_hotkey=true`（没写 = 关）退回 1.1.9，下面是那时的做法；玩家设过的键还在设置文件里，打开后照常生效。

设置页可录入一个组合键，默认不绑定，录入后立即生效。按一次展开详情，再按一次收起；鼠标离开后的 5 秒自动收起规则仍适用。支持 Ctrl 或 Alt 加字母、数字、F1～F11，可再加 Shift；不支持多段组合键、Win 键和 Windows 保留的 F12。点“清空”禁用快捷键；仍可点击浮窗查看详情，按需模式下将鼠标移到原按钮位置附近唤出。

快捷键在常驻按钮和按需按钮两种模式下都能使用，按钮完全隐藏时也能展开详情。它只切换英雄、出装、加点详情，不关闭或切换海克斯推荐标签。三选一推荐仍自动显示，三选一结束后自动隐藏。

Windows 桌面下通过系统热键注册接收通知，不安装键盘钩子，不模拟按键，也不增加截图、识别或定时轮询。复用 250ms 界面刷新，根据游戏 / 选英雄是否处于前台注册或释放；切到其他软件、离开选英雄界面、关闭浮窗总开关或退出助手时释放。处理排队的按键通知时再次核对前台和总开关。按键不会主动激活详情窗口或把焦点从游戏转走。

录入时尝试注册检查占用，被占用或不支持的键不替换原来的设置，设置页下面一行写原因；游戏回到前台启用失败时，设置页保留失败原因，下次切回游戏重试。系统能检测已经注册的全局组合键，不能检测游戏或其他程序内部的按键，也不能保证游戏不同时响应。建议避开 F 键及游戏、聊天、录屏软件中已使用的键位，录入后应在自己的游戏环境中验证。

新增配置项 `overlay_hotkey` 为字符串，空字符串代表禁用；旧版配置缺少时不自动绑定，其他配置和校准数据沿用。1.1.6 早期试用曾默认绑定 `Ctrl+Shift+F8`：只有未在 `user_set` 标记为主动设置的旧默认会迁移为禁用，其他自定义值和已清空的值保留；已被标记的旧键位可在设置里手动清空。快捷键作为个人键位存储，不增加云控项或运行依赖。手改成不支持的字符串时提示并停用，不静默改成其他按键。

## 和识别降载的区别

按需按钮减少平时覆盖游戏的置顶窗口，不停止截图，不调整 OCR 或扫描间隔。“空闲时减少识别开销”（默认关闭，只能云控打开）在截图后减少部分 OCR。

当前反馈中的“无边框下帧率封顶到刷新率”和“团战瞬间掉帧”仍需分开验证。退出助手同时停止了浮窗、截图和识别，单凭退出后恢复不能确定根因。本功能也不能保证解决帧率封顶；需在问题机器上比较默认显示、按需隐藏且鼠标远离热区、云控彻底隐藏浮窗和退出助手的表现。比较时保持场景及游戏设置一致，关闭额外调试截图。

## 兼容与验证

布尔设置 `overlay_on_demand` 1.1.7 起默认 `true`，读设置文件时一律改为 `true` 并从 `user_set` 去掉；只有云控 force 能关掉。未知配置键保留，校准文件、数据格式、依赖和 Python 版本不变。

离屏自动测试覆盖窗口实际隐藏、反复空闲刷新不先显示再隐藏、鼠标唤出与超时、左右位置、模拟缩放及负屏幕坐标、窗口移动、前后台切换、三选一和选人胜率、手动选英雄提示、第一次选择前固定显示与选完隐藏、设置即时保存和云控撤销。模拟缩放用例不能代替多显示器实测。

本轮未测得游戏 FPS，也没有完成问题机器、Windows 10 或多显示器 DPI 切换的实机验证。未增加运行库不代表已经验证发行包增量升级，最终产物仍须按现有发布流程检查。
